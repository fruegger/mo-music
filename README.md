# mo-music

Workspace root containing multiple projects.

- [`audan/`](audan/) -- a suite of music-information-retrieval command line utilities (Rust)
- [`mixer/`](mixer/) -- seeded random mixes of multitrack stems (Slakh2100, MUSDB18) with labels, for model training (Python)
- [`trainer/`](trainer/) -- model training on the mixer's snippets, starting with instrument recognition (Python)
- [`repo/prototype/sources.log`](repo/prototype/sources.log) -- the datasets in use: location and licence
